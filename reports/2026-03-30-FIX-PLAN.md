## Go / no-go checklist

Go only if all are true:

- No obviously fake integrations remain in release-facing UI
- Bundle verification claims accurately match what is actually verified
- Import, create, and verify flows are clear and reliable
- Persisted local data has an intentional privacy posture
- Legacy/demo agents are labeled honestly
- Small-screen layout is usable
- External asset/privacy exposure is reduced or explicitly accepted
- Package identity and scripts are cleaned up
- Smoke tests exist for critical flows
