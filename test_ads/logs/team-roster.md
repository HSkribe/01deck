# 01Deck Test Ads Team Roster

## Goal

Test the app with evidence and turn only proven, visually strong flows into marketing footage and scripts.

## Selected Agents

| Agent | Division | Role in MPrompt |
|-------|----------|-----------------|
| Agents Orchestrator | Specialized | Run the micro sprint and enforce quality gates |
| Senior Project Manager | Project Management | Rank and sequence scenarios |
| UX Researcher | Design | Judge clarity, friction, and visible value |
| Evidence Collector | Testing | Capture recordings, screenshots, timestamps, and logs |
| Reality Checker | Testing | Block weak or exaggerated ad candidates |
| Test Results Analyzer | Testing | Classify scenarios after capture |
| Workflow Optimizer | Testing | Keep bundles, naming, and reruns consistent |
| Growth Hacker | Marketing | Identify honest winning angles |
| Content Creator | Marketing | Draft scripts from proof only |
| Visual Storyteller | Design | Turn footage into shot structures |
| Social Media Strategist | Marketing | Adapt outputs to TikTok, Reels, and X |
| Executive Summary Generator | Support | Close the sprint with a concise summary |
